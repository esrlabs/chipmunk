### Selecting and copying logs

Rows in the logs table are selected like files in a file manager: a click selects
a single row, `Ctrl`/`Cmd` + click adds or removes one row, and `Shift` + click
selects the range up to the clicked row. The selection is shared between the main
logs table and the search results.

Selected rows can be copied to the clipboard with `Ctrl+Shift+C` (`Cmd+Shift+C`
on macOS) or from the table context menu. Copying from the search results is
limited to the rows shown there, while the main table copies the whole selection.
